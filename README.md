# Job Application Platform

A production-oriented Job Application backend built with Java and Spring Boot.

The project starts with a Spring Boot monolithic application for managing Jobs and Companies and is being progressively evolved into a distributed microservices-based backend.

The goal of this project is to gain hands-on experience with real-world Java backend and distributed system technologies.

## 🚀 Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Spring Cloud
- OpenFeign
- Apache Kafka
- Redis
- REST APIs
- Docker
- Maven
- Lombok
- Postman
